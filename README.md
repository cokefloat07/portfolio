# 🚀 Portfolio Website

An elite, animated portfolio website built with React.js, showcasing frontend development expertise with stunning animations and modern design.

## ✨ Features

- 🎨 **Cosmic Dark Theme** with gradient accents
- ✨ **Custom cursor** with magnetic buttons
- 🌌 **Interactive particle background** with mouse interaction
- 📝 **Typewriter effect** on hero section
- 🎭 **Scroll-triggered animations** throughout
- 📱 **Fully responsive** design
- 🃏 **Glow cards** with mouse-tracking effects
- 📊 **Animated skill bars** and project filters
- 📧 **Working contact form** with EmailJS
- 🔄 **Loading screen** with animation
- 📜 **Scroll progress indicator**
- 🎯 **Section navigation** with active states

## 🛠️ Tech Stack

- React.js 18
- Framer Motion
- React Icons
- EmailJS
- React Hot Toast

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/cokefloat07/portfolio.git

# Navigate to directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
